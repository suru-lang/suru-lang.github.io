The whole language on one page. Each row is something you can write, with what it means. Every example here runs as written; the tutorial explains them step by step, and you can try them in the playground.

01Particles

Particles mark each argument's role, so the order is free.

WriteMeaning
をthe thing acted on (object)
にthe target: 5 を 数列 に 追加する
でwith / by: 10 を 2 で 割った数にする
からfrom: 1 から 5 を 範囲にする
へ・よりtoward / than
とjoins a list: 1 と 2 と 3
のa property or field: 数列 の 長さ
がthe subject of a test: n が 偶数である

03Functions

A function name ends in する. Define it with とは and call it with the same particles.

WriteMeaning
x を 二乗する とは x * x ですdefine a function
5 を 二乗するcall it
a を b で 割った数にする とは a / b ですtwo arguments, told apart by particles
数 を 二乗する は 数 を 返すdeclare its type (optional)
n が 偶数である とは n % 2 が 0 ですa test: ends in である; …でない is its negation
0 を 階乗する とは 1 ですa case for one value (recursion)
ただし 合計 とは a + b ですa local name, on the line after the definition

04Chains and functions as values

WriteMeaning
3 を 二乗して 1 に 加算するして passes the result to the next call
数列 の それぞれ を 二乗するapply to each element
二乗することthe function itself, as a value
（10 を 加算すること）partial application
数列 を （10 を 加算すること） で 写像するmap
数列 から 偶数であること で 選別するfilter
数列 を 0 から 加算すること で 畳み込みするfold
（x を 受け取って x > 2 を 返すこと）an anonymous function

05Conditions and cases

WriteMeaning
もし c ならば a そうでなければ bif / else
かつ　またはand, or
=　≠　<　>　<=　>=comparison
もし 形 が … ならば …cases by shape (see the example below)
Example
図形 とは 半径 の 円 か 幅 と 高 の 長方形 です

形 を 面積にする とは
  もし 形 が
    半径 の 円 ならば 3 * 半径 ^ 2 です
    幅 と 高 の 長方形 ならば 幅 * 高 です

07Actions (input and output)

Steps that read or write go in a 以下の手順です … 以上です block, in order.

WriteMeaning
「やあ」 を 表示するprint a line
x とは … を 入力した 結果the result of an action, inside steps
… は 無 を 返す 入出力動作the type of an action
Example
挨拶する は 無 を 返す 入出力動作
挨拶する とは 以下の手順です
  名前 とは 「お名前は? 」 を 入力した 結果
  「こんにちは、」 + 名前 + 「さん」 を 表示する
  以上です
