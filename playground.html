    No Japanese keyboard? How to type 「する」 here
    
Turn on your computer’s Japanese input method (IME), type the reading in romaji, press Space to convert to kanji and Enter to confirm. It works in the editor above like anywhere else. The full guide is on Typing Japanese, and you can learn it step by step in the typing practice.

    

      
Windows
Settings → Time & language → Add a language → 日本語. Set its keyboard layout to English keyboard (101/102 key).
Win+Space switches keyboards, Alt+` switches A/あ.

      
macOS
System Settings → Keyboard → Input Sources → Edit… → + → Japanese → Romaji.
Ctrl+Space or the 🌐 key switches between ABC and Japanese.

      
Ubuntu
sudo apt install ibus-mozc, log out and in, then Settings → Keyboard → Add Input Source → Japanese (Mozc).
Super+Space switches sources.

Full-width spaces, digits and ＋＊ are fine, so you can stay in Japanese mode. But - and / type ー and ・ there: switch to A for minus and division, and for Latin names like x.

  


  
What works here. The language, type checking and the standard library work as they do on your computer, including 「算術」 (math), 「乱数」 (random numbers), 「時間」 (time) and JSON. Files go to a temporary file system inside the page, which is gone when you leave. Things that need more of the operating system do not work: processes, threads, signals, sockets and HTTP, and C libraries other than the C standard library. The first visit downloads Python for the browser (Pyodide, about 10 MB), then your browser keeps it. To use everything, install する.
