    Typing practice

    Practice typing 日本語

    Think Japanese looks cool but have never typed it? You need no Japanese keyboard and no Japanese. In about ten minutes you will turn on the Japanese input that is already in your computer, then type hiragana, katakana and kanji. Type each word and press Submit (回答); when it matches, you move on.

    1. Open Settings → Time & language → Language & region.
    2. Click Add a language, choose 日本語 (Japanese) and install it. This adds Microsoft IME.
    3. Click ⋯ → Language options next to Japanese and set Keyboard layout to English keyboard (101/102 key), then restart.
    4. Press Win+Space to pick Japanese, then Alt+` until the taskbar shows あ.
    1. Open System Settings → Keyboard, and next to Input Sources click Edit….
    2. Click +, choose Japanese, then Romaji, and click Add.
    3. Press Ctrl+Space (or the 🌐 key) until the menu bar shows あ.
    1. In a terminal, run sudo apt install ibus-mozc, then log out and back in.
    2. Open Settings → Keyboard, click + Add Input Source, and choose Japanese → Japanese (Mozc).
    3. Press Super+Space to pick Mozc. If it still types Latin letters, choose Input Mode → Hiragana from the top bar.
    1. iPhone and iPad: Settings → General → Keyboard → Keyboards → Add New Keyboard → Japanese → Romaji. Tap 🌐 on the keyboard to switch.
    2. Android (Gboard): Gboard settings → Languages → Add keyboard → 日本語 → QWERTY. Tap 🌐 to switch.

    More detail, including fcitx5 and other settings, is on Typing Japanese.
