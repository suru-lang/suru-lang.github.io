Libraries

Official libraries

Besides the standard library, the suru-lang organization keeps small libraries in their own repositories. Add one to a kumu project with kumu 追加 and load it by its name. Each has a README and, for most, API pages on Read the Docs. This list is also in the documentation.

01Using a library

Add the libraries to your project. kumu also fetches what they depend on:

terminal
$ kumu 追加 github.com/suru-lang/db
$ kumu 追加 github.com/suru-lang/sqlite

Then load them by name. This uses 「蔵」 with its SQLite driver:

本体.suru
「蔵」 を 読み込んで 使う
「SQLite」 を 読み込んで 使う

主処理する とは 以下の手順です
  db とは 「店.db」 を SQLite駆動 で DB開封した 結果
  db に 「CREATE TABLE IF NOT EXISTS 品 (名前 TEXT, 値段 REAL)」 を DB実行する
  db を DB閉鎖する
  「以上です」 を 表示する
  以上です

主処理する

Libraries that call a C library need it on the system. kumu checks the 外部依存 in each library's 組.suru and tells you how to install it if it is missing.

03Web framework 屋台

屋台 (suru-lang/web, 「屋台」, する 0.11.0 or later) is a web framework built from http, 雛形 and 台帳. List the routes with 【道】 and write a handler for each. kumu 新規 店 --対象 web creates an app with everything in place. See the section on the home page and the API documentation.

04ROS 2

rclsuru (「rclsuru」) writes ROS 2 nodes in する that talk to rclcpp and rclpy nodes. Start with the short tutorial.
