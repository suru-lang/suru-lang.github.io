ライブラリ

公式ライブラリ

標準ライブラリのほかに、suru-lang の organization には、それぞれのリポジトリに置いた小さなライブラリがあります。kumu のプロジェクトで kumu 追加 して、名前で読み込みます。どれにも README があり、ほとんどは Read the Docs に API のページがあります。この一覧はドキュメント(英語)にもあります。

01ライブラリを使う

プロジェクトにライブラリを足します。依存しているものも kumu が取ってきます。

terminal
$ kumu 追加 github.com/suru-lang/db
$ kumu 追加 github.com/suru-lang/sqlite

名前で読み込みます。次は 「蔵」 と SQLite の駆動を使う例です。

本体.suru
「蔵」 を 読み込んで 使う
「SQLite」 を 読み込んで 使う

主処理する とは 以下の手順です
  db とは 「店.db」 を SQLite駆動 で DB開封した 結果
  db に 「CREATE TABLE IF NOT EXISTS 品 (名前 TEXT, 値段 REAL)」 を DB実行する
  db を DB閉鎖する
  「以上です」 を 表示する
  以上です

主処理する

C のライブラリを呼ぶものは、そのライブラリをシステムに入れておきます。kumu は各ライブラリの 組.suru の 外部依存 を確かめ、なければ入れ方を示します。

03ウェブフレームワーク 屋台

屋台(suru-lang/web、「屋台」、する 0.11.0 以上)は、http・雛形・台帳 で作ったウェブフレームワークです。【道】で道筋を並べ、それぞれの処理を書きます。kumu 新規 店 --対象 web で、すべてそろったアプリができます。トップの節と API のドキュメント(英語)を見てください。

04ROS 2

rclsuru(「rclsuru」)で、rclcpp・rclpy のノードと話す ROS 2 のノードを する で書けます。まず短いチュートリアルから。

06自分で作る

組.suru があってタグを付けた Git のリポジトリなら、どれでも kumu 追加 で足せます。中央の登録所はありません。ライブラリを公開するを見てください。
