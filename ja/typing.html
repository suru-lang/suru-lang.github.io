英語のキーボードで 日本語 を打つ

このページについて: これは、英語話者のための日本語入力の手引きを、日本語に忠実に訳したものです。ここまで読めている方には、たぶん要りません。もしこの文を日本語入力なしで読めているなら、それはそれで、すごいことです。

する のプログラムは日本語で書きますが、日本語のキーボードは要りません。どのコンピューターにも、日本語入力システム(IME)がもう入っています。音をローマ字で打つと、hyouji を 表示 にしてくれます。このページでは、その入れ方と、要るいくつかのキーを説明します。

01必要なもの

日本語は3つの文字を使います。ひらがな(あいう)、カタカナ(アイウ)、漢字(表示)です。IME では読みをローマ字で打つとひらがなで出て、Space を押すと漢字に変換されます。Windows と macOS では何もダウンロードしなくてよく、Ubuntu ではパッケージを1つ入れます。

2つのモードをいつも行き来することになります。

  • 日本語モード(表示は あ): 文字がかなになります。
  • 英語モード(表示は A): キーボードがいつもどおりに動きます。

英語(US)のキー配列はそのまま残します。日本語の IME はその上で動きます。

02Windows

入れ方

  1. 設定 → 時刻と言語 → 言語と地域 を開きます。
  2. 言語の追加 を押し、日本語 を選んで入れます。表示言語にする必要はありません。これで Microsoft IME が入ります。
  3. 日本語の横の ⋯ → 言語のオプション を押します。キーボード レイアウト で 英語キーボード (101/102 キー) を選び、再起動します。こうしないと、Windows が日本語キーボードだと思い込み、記号のキーで違う文字が出ることがあります。

モードの切り替え

  • Win + Space で、英語と日本語のキーボードを切り替えます。
  • 日本語のキーボードの中では、Alt + `(1 の左のキー)で あ と A を切り替えます。タスクバーの A/あ を押してもかまいません。
  • 代わりに Ctrl + Space を使いたいときは、Microsoft IME の設定(A/あ を右クリック → 設定)の キーとタッチのカスタマイズ で割り当てます。

03macOS

入れ方

  1. システム設定 → キーボード を開き、入力ソース の横の 編集… を押します。
  2. + を押して 日本語 を選び、ローマ字入力(日本語キーボードが要る かな入力 ではなく)を選んで 追加 を押します。
  3. ABC か U.S. は一覧に残します。Space を押したときだけ変換したい人は、日本語の入力ソースのオプションで ライブ変換 を切れます。

モードの切り替え

  • Ctrl + Space で前の入力ソースに切り替わるので、ABC と日本語を行き来できます。
  • 最近の Mac では、🌐(fn)キーでも同じことができます。キーボードの設定で 🌐キーを押して → 入力ソースを変更 にします。
  • または、入力ソースの設定で Caps Lock キーで ABC 入力モードに切り替える を入れ、Caps Lock を使います。

04Ubuntu

Ubuntu のデスクトップは IBus を使い、日本語のエンジンは Mozc(Google 日本語入力のオープンソース版)です。

入れ方(IBus、既定)

端末
$ sudo apt install ibus-mozc
  1. ログアウトして、もう一度ログインします。
  2. 設定 → キーボード を開き、+ 入力ソースを追加 を押して 日本語 → 日本語 (Mozc) を選びます。英語 (US) も残します。

モードの切り替え

  • Super + Space で、英語 (US) と Mozc を切り替えます。
  • Mozc でもローマ字のままのときは、上のバーの表示を押して 入力モード → ひらがな を選びます。Mozc の ツール → プロパティ → キー設定(パッケージ mozc-utils-gui)で、オンとオフのキーを足せます。

fcitx5 で使う

fcitx5(KDE でよく使われます)がよければ、fcitx5-mozc を入れて im-config -n fcitx5 を実行し、ログアウトして、Fcitx の設定で Mozc を足します。そうすると Ctrl + Space で日本語のオンとオフを切り替えられます。

端末
$ sudo apt install fcitx5-mozc
$ im-config -n fcitx5

05ローマ字で打つ

日本語モードで読みを打つと、下線付きで出ます。そのあとは次のとおりです。

  • Space で漢字に変換します。もう一度 Space(または矢印キー)で別の候補を選びます。
  • Enter で確定します。Space を押さずに Enter を押すと、ひらがなのままになります。
  • Esc で取り消します。IME が言葉の区切りを間違えたら、Shift + ←/→ で区切りを短く・長くします。
  • カタカナにするには、Enter の前に F7(Windows と Mozc)、Mac では Ctrl + K を押します。Windows と Mozc では、F10 で打ったものをローマ字に戻せます。

たいていの読みは聞こえるとおりに打てます。つまずきやすいのは次のものです。

出したい字打つわけ
をwo助詞は「お」と読みますが、o では お が出ます。
はha助詞の とは は「とわ」と読みますが、toha と打ちます。
んnn子音の前なら n 1つで出ます(kansuu → かんすう)が、母音・y の前や終わりでは nn と打ちます: konnnichiha → こんにちは。
っtt・kk…次の子音を2つ重ねます: kitte → きって。
きゃkya小さい ゃゅょ は子音+y のあとに付けます。小さいかなだけなら x か l を前に付けます: xtu → っ。
ー-カタカナの伸ばす音です: ke-ki → ケーキ。
ひょうhyou長い「お」は おう と書きます: 表示 は hyouji、以上 は ijou。

06括弧と句読点

日本語モードでは、いくつかのキーが日本語の記号を打ちます。する で使うのは次のものです。

『 』[ のあと Spaceひらがなを含む名前: 『おやつの数』
【 】[ のあと Space、または kakko と打って変換導出と雛形: 【JSON】
（ ）Shift + 9 0まとめる。全角と半角の括弧のどちらでも動きます
、,句読点の書き方での区切り
。.句読点の書き方での文の終わり

気をつけること: 日本語モードでは、- は伸ばす音の ー を、/ は ・ を打ちます。どちらも する では引き算や割り算になりません。計算は英語モードに切り替えて打つか、× と ÷ を使います。x のようなローマ字の名前も、英語モードで打ちます。

07する のプログラムを打つ

する の言葉は空白で区切ります。日本語モードでは Space が変換なので、確定したあとにもう一度押すと空白になります。Windows ではこの空白は既定で全角の 　 ですが、する は半角の空白と同じに受け付けます。全角の数字や ＋＊ も受け付けます。ですから、日本語モードのまま1行を打ちきれます。

zenkaku.suru
値段　とは　１２００　です
値段　＊　２
「する」　を　表示する
2400
する

半角の空白がよければ、Microsoft IME の設定の 全般 → スペース を 常に半角 にできます。Windows では Shift + Space でもう片方の幅の空白が打てます。よく使う言葉の打ち方は次のとおりです。

言葉打つ意味
表示するhyoujisuru表示する
とはtohaとは
ですdesuです(定義の終わり)
をwo目的語の助詞
加算するkasansuru加算する
以下の手順ですikanotejunndesu以下の手順です
以上ですijoudesu以上です(まとまりを閉じる)

IME が違う漢字を選んだら、もう一度 Space を押して一覧から選びます。選んだものは覚えてくれるので、2回目からは速くなります。自分の関数の名前を、ユーザー辞書に足すこともできます。

08エディターに打ってもらう

名前を打つのは1回だけで済みます。VS Code に する の拡張 を入れると、次のことができます。

  • 補完(Ctrl + Space)で、自分の関数と値・組み込み関数・標準ライブラリ・キーワードが出ます。表 のように最初の漢字を打って、表示する を選びます。ひらがなを含む名前は、はじめから 『』 で囲んで入ります。一覧は打っているうちにひとりでにも出るので、Ctrl + Space がたいてい入力ソースの切り替えになっている Mac でも助かります。
  • （・「・『 を打つと、閉じる括弧を足してくれます。
  • 関数の上にマウスを置くと、どの助詞を取るかが出るので、調べなくて済みます。

注釈や自分の変数の名前は英語でもかまわないので、日本語モードにするのは言語の言葉を打つときだけです。用意はできましたか。入門に進むか、試すのページで動かしてみてください。
