入門

する を、ひと息で

「こんにちは」から、コンパイルしたプログラムまでを順にたどります。このページの例はどれも する で実際に動かしたもので、出力はそのとき表示されたとおりです。

01準備

PyPI からインタプリタを入れます(Homebrew なら brew install suru-lang/suru/suru)。Python 3.10 以降があれば、ほかには何も要りません。

端末
$ pip install suru-lang
$ suru --version
する 0.9.1

次の1行を 挨拶.suru に保存して、suru 挨拶.suru で動かします。

挨拶.suru
「こんにちは、世界」 を 表示する
こんにちは、世界

文字列は 「」 で囲みます。# から行の終わりまでは注釈です。

ヒント: ファイルを付けずに suru を起動すると対話モードになります。式を入力すると、値と型を 9 は 数 のように並べて答えます。

02値と名前

とは で名前に値を付けます。名前は漢字・カタカナ・英字で書きます。式だけの行は、その値を表示します。

値.suru
税率 とは 0.1 です
値段 とは 1200 です
値段 * （1 + 税率）
「する」 + 「言語」
1320
する言語

算術は + - * / % ^ です(全角の ＋ × ÷ も使えます)。+ は文字列もつなぎます。括弧は半角でも全角でもかまいません。

03関数と助詞

関数の名前は「する」で終わる動詞です。引数に名前を付けた呼び出しの形を書き、とは の後に本体を書けば定義になります。終わりの です は文として読みやすくするためのもので、書かなくても意味は同じです。

二乗.suru
x を 二乗する とは x * x です
5 を 二乗する
25

引数には格助詞を付けます。呼び出すときは助詞で引数が決まるので、順番は自由です。

割り算.suru
a を b で 割った数にする とは a / b です
10 を 2 で 割った数にする
2 で 10 を 割った数にする
5
5
助詞おおよその役例
を主な対象x を 二乗する
に相手・行き先3 を 5 に 加算する
で手段・道具10 を 2 で 除算する
から起点10 から 3 を 減算する
へ方向s を 「a」 から 「b」 へ 置換する
より比べる相手(自分の関数で自由に使えます)

1つの関数で同じ助詞は1回だけです。引数が足りない呼び出しや、受け取らない助詞を渡す呼び出しは、実行する前にエラーになります。

04リスト

と で並べるとリストになります。の の後に 先頭・残り・最後・長さ を書くと、リストの性質を取り出せます。

リスト.suru
数列 とは 1 と 2 と 3 と 4 です
数列 の 先頭
数列 の 長さ
数列 を 加算する
5 を 数列 に 追加する
1
4
10
（1 と 2 と 3 と 4 と 5）

組み込みの 加算する は、リストを渡すと全部を足します。値はどれも変更できないので、追加する は新しいリストを返します。空のリストは 空 です。

05「して」でつなぐ

「する」を「して」にすると、その結果が次の関数の「を」に入ります。長い処理も文のように読めます。

パイプ.suru
x を 二乗する とは x * x です
3 を 二乗して 1 に 加算する
1 と 2 を 加算して 二乗する
10
9

06関数を値として使う

「すること」で終わらせると、関数そのものを値として渡せます。前に引数を書けば部分適用です。名前のない関数は x を 受け取って … を 返すこと と書きます。

高階関数.suru
x を 三倍する とは x * 3 です
数列 とは 1 と 2 と 3 と 4 です
数列 の それぞれ を 三倍する
数列 から （x を 受け取って x > 2 を 返すこと） で 選別する
数列 を 0 から 加算すること で 畳み込みする
数列 を （10 を 加算すること） で 写像する
（3 と 6 と 9 と 12）
（3 と 4）
10
（11 と 12 と 13 と 14）

それぞれ は要素ごとの呼び出し(map)、選別する は filter、畳み込みする は fold、写像する は関数の値を使う map です。

07条件と述語

もし … ならば … そうでなければ … は式なので、両方の枝が必要です。が は等しいかどうかを調べます。

「である」で終わる名前は述語(真か偽を返す関数)です。主語は「が」で受け、「でない」で否定し、「であること」で値になります。

偶数.suru
n が 偶数である とは n % 2 が 0 です
n を 判定する とは もし n が 偶数である ならば 「偶数」 そうでなければ 「奇数」 です
7 を 判定する
4 が 偶数である
3 が 偶数でない
（1 と 2 と 3 と 4） から 偶数であること で 選別する
奇数
真
真
（2 と 4）

条件は かつ・または でつなげます。

08再帰と場合ごとの定義

引数名の代わりに値や形を書くと、場合ごとに関数を定義できます。上から順に、当てはまった最初の定義を使います。

階乗.suru
0 を 階乗する とは 1 です
n を 階乗する とは n * （n - 1 を 階乗する） です
10 を 階乗する
3628800

呼び出しの結果を計算に使うときは n * （n - 1 を 階乗する） のように括弧で囲みます。リストは 先頭 は x で 残り は 他 で先頭と残りに分けられ、空 は空のリストに当てはまります。

09自分の型

か で、型がとりうる形を並べます。もし 値 が の後に字下げした行を並べるとパターンマッチです。構造は Python のように字下げで決まります。

図形.suru
図形 とは 半径 の 円 か 幅 と 高 の 長方形 です

形 を 面積にする とは
  もし 形 が
    半径 の 円 ならば 3 * 半径 ^ 2 です
    幅 と 高 の 長方形 ならば 幅 * 高 です

5 の 円 を 面積にする
幅 は 2 で 高 は 3 の 長方形 を 面積にする
75
6

値は順番どおり(5 の 円)にも、名前付き(幅 は 2 で 高 は 3 の 長方形)にも作れます。場合分けで形が足りなければ、実行する前にエラーになります。組は 点 とは 横 と 縦 の 組、型クラスは「性質」と書きます。

10入出力動作と手順

表示する や 入力する のような副作用は、その場では何もせず「入出力動作」という値を作ります。一番外に書いた入出力動作が行われます。いくつかの入出力動作を順に行うときは 以下の手順です と 以上です の間に1行に1つずつ並べ、… した 結果 で入出力動作の結果に名前を付けます。1行目の型の宣言は「何も返さない入出力動作」という意味です。

挨拶する.suru
挨拶する は 無 を 返す 入出力動作
挨拶する とは 以下の手順です
  名前 とは 「お名前は? 」 を 入力した 結果
  「こんにちは、」 + 名前 + 「さん」 を 表示する
  以上です

挨拶する
お名前は? 太郎
こんにちは、太郎さん

入力してから 表示する のように「してから」で、入出力動作の結果を次の関数に渡せます。純粋な計算と副作用が分かれるので、どこで何が起きるかが読み取りやすくなります。

11句読点の書き方

「。」か「、」のある行は、文字の種類(漢字・かな・数字)の境目で単語を切ります。「。」で文が終わり、「、」は読みやすさのための区切りです。丁寧語の「します」は「する」と同じ意味です。

句読点.suru
aとbを平均するとは、合計/2です。ただし、合計とは、a+bです。
3と5を平均します。
「できました」を表示します。
4
できました

ただし は、直前の定義に局所定義を付け足します。ひらがなは助詞に使うので、ひらがなを含む名前は 『おやつの数』 のように 『』 で囲みます。

12型

実行する前に、すべての式の型を推論して調べ、合わないところがあれば止めます。エラーは行と文字の位置と印つきで、日本語で出ます。

間違い.suru
x を 二乗する とは x * x です
「三」 を 二乗する
エラー: 2行目 7文字目: 「二乗する」の「を」には数が必要ですが、文字列が渡されています
  「三」 を 二乗する
            ^

型は書かなくてもかまいませんが、は … を 返す で宣言することもできます。

宣言.suru
数 を 二乗する は 数 を 返す
x を 二乗する とは x * x です
4 を 二乗する
16

型の名前には 数・文字列・真偽・数 の リスト・文字列 を 返す 入出力動作(短く 文字列 の 動作 とも)などがあります。suru --検査 ファイル.suru で、実行せずに調べるだけにもできます。

13読み込みと標準ライブラリ

「数学」 を 読み込む で同じフォルダの 数学.suru を読み込み、中の名前は 数学内の二乗する のように使います。「数学」 を 読み込んで 使う なら前置きなしで使えます。標準ライブラリも同じように読み込みます。

標準.suru
「標準」 を 読み込んで 使う
3 と 1 と 2 を 整列する
「a,b,c」 を 「,」 で 分割する
1 から 5 を 範囲にする
（1 と 2 と 3）
（「a」 と 「b」 と 「c」）
（1 と 2 と 3 と 4 と 5）

ほかに ファイル・時間・JSON・スレッド・プロセス などがあります。ファイルの終わりに X と Y は 非公開とする。 と書くと、その名前を外から見えなくできます。

14C の関数を呼ぶ

C の呼び出し規約の関数なら、何でも する から呼べます(FFI)。外部の「m」 を 読み込む で C のライブラリ libm をつなぎます。libc は読み込まなくても使えます。関数ごとに、する での名前と 「」 に入れた C の名前、引数と結果の型を書きます。

外部.suru
外部の「m」 を 読み込む

x を y で 累乗する とは 外部の「pow」 で 小数 を 小数 で 受け取って 小数 を 返します

以下は外部の関数です
  小数 を 平方根にする は 「sqrt」 で 小数 を 返します
  小数 を 床にする は 「floor」 で 小数 を 返します
以上です

以下は外部の入出力動作です
  文字列 を 一行出力する は 「puts」 で 整数 を 返します
以上です

2 を 10 で 累乗する
2.0 を 平方根にする
2.7 を 床にする
「こんにちは」 を 一行出力する
1024
1.4142135623730951
2
こんにちは

1つなら … とは 外部の「C の名前」 で の後に、定義と同じ助詞で引数の型を書き、受け取って、結果の型を書く1行で定義します。たくさんなら 以下は外部の関数です と 以上です の間に1行に1つずつ並べます。副作用のある関数は 以下は外部の入出力動作です に書きます。表示する と同じく入出力動作になり、行ったときに呼ばれます。

使える型は 数(int64)・小数(double)・整数(int)・単精度(float)・真偽・文字列(char*)・番地(ポインタ)・バイト列・無(void)です。C に渡す引数を並べ替えたり定数を足したりするときは、r を 読取する とは 「f」（r と 0） で 番地 を 受け取って 番地 を 返します のように名前を付けて書きます。SQLite・PCRE2・OpenSSL・SDL3 などのライブラリも、こうして する だけで包んであります(GitHub の suru-lang のリポジトリ)。

15ネイティブのバイナリ

同じプログラムを、LLVM を通して1つの実行ファイルにできます。手元に clang が必要です。suru --翻訳 は元の版のコンパイラ、Go で書いた suruc は同じことをずっと速く行います。

端末
$ go install github.com/suru-lang/suru/cmd/suruc@latest
$ suruc 階乗.suru
$ ./階乗
3628800

プロジェクトには kumu(組む)を使います。設定ファイル 組.suru も する の文です。

端末
$ go install github.com/suru-lang/suru/cmd/kumu@latest
$ kumu 新規 挨拶      # 新しいプロジェクト「挨拶」(kumu new も可)
$ cd 挨拶
$ kumu 実行           # 組んで動かす(kumu run も可)
「挨拶」0.1.0 を組みました(出力/挨拶)
こんにちは

16試験

試験は する そのもので、コードのすぐそばに書きます。定義の下の 例えば … は … です はその定義の例、以下は「名前」の試験です … 以上です は試験のまとまりです。どちらもファイルと一緒に型を検査し、プログラムとして動かすときは飛ばし、suru --試験 で動きます。

二倍.suru
数 を 二倍する は 数 を 返す
x を 二倍する とは x * 2 です
例えば （2 を 二倍する） は 4 です

以下は「二倍」の試験です
  （-3 を 二倍する） を -6 に 一致確認する
  以上です
端末
$ suru --試験 二倍.suru
✓ 二倍.suru 二倍するの例(3行)
✓ 二倍.suru 二倍

合格 2・不合格 0

kumu のプロジェクトでは、kumu 試験 がこれらと 試験/ のフォルダの試験を動かします。CI まで含めた全部は試験のページにあります。
