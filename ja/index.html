助詞括弧ではなく、助詞で

02 / 言語

機能おもちゃではない、本物の言語

日本語の見た目の下には、今どきの関数型言語の中身があります。型の推論、自分で定義する型、パターンマッチ、そして副作用を値として分けて扱う仕組みです。

型

型の推論と検査

Hindley–Milner の型推論で、実行する前にプログラム全体の型を調べます。型は書かなくてよく、書きたいところには宣言できます。

形

データとパターンマッチ

組(名前付きタプル)、選択肢のある型、型の引数、条件付きのパターンマッチ、場合ごとの関数定義、性質(型クラス)。

動

副作用は「入出力動作」

表示や入力は「入出力動作」という値です。「以下の手順です」から「以上です」までに並べて順に行います(Haskell の do 記法にあたります)。

速

ネイティブのバイナリ

LLVM IR を出し、clang で1つの実行ファイルにします。Go で書いたコンパイラ suruc は、IR を作るまでが元の版の 14〜35 倍速くなります。

並

本当に並列なスレッド

スレッドは CPU のコアの数まで同時に動きます。通路・ロック・枠・箱で値をやりとりし、GC もスレッドに対応しています。

繋

C・C++・Go を呼ぶ

型を宣言して名前を指すだけで、libc や libm、自分で作った共有ライブラリの関数を呼べます。

03 / 文体

文体2つの書き方

単語の間に空白を入れて書くことも、ふだんの日本語のように空白なしで「。」と「、」で書くこともできます。丁寧語の「します」も使えます。同じファイルで混ぜてもかまいません。

空白の書き方
a と b を 平均する とは 合計 / 2 です
ただし 合計 とは a + b です

3 と 5 を 平均する
4
句読点の書き方
aとbを平均するとは、合計/2です。ただし、合計とは、a+bです。
3と5を平均します。
「できました」を表示します。

04 / ライブラリ

標準必要なものは、そろっています

標準ライブラリそのものが する で書かれています。「名前」 を 読み込む で、ファイル、時間と暦(和暦も)、JSON、TCP、スレッドと通路、プロセスとパイプ、共有メモリ、シグナルが使えます。インタプリタでも、コンパイルしたバイナリでも、同じコードが動きます。HTTP サーバー(静的ファイル配信とクライアントつき)・SQLite・正規表現は、kumu 追加 で足す標準の外のライブラリです。ほかにも公式ライブラリ(英語)に、テンプレート、SQLite・PostgreSQL・MySQL の駆動つきのデータベースの層、O/R マッパー、SDL3 の GUI、Python の呼び出しがあります。

05 / ウェブ

屋台する で書くウェブフレームワーク

屋台(suru-lang/web)は、HTTP サーバー・テンプレートエンジン 雛形・O/R マッパー 台帳 をまとめたものです。【道】で道筋を1行に1つずつ並べ、それぞれの処理を書きます。インタプリタでもコンパイルしたバイナリでも同じコードが動きます。kumu 新規 店 --対象 web で、道筋・テンプレート・静的ファイル・試験のそろったアプリができます。する 0.11.0 以上が要ります。API は Read the Docs のドキュメント(英語)にあります。

06 / ROS 2

ロボットROS 2 のノードも する で

rclsuru は、する で ROS 2 のノードを書くためのライブラリです。トピック・サービス・アクション・パラメータ・ログ・ROS の時刻が使え、rclcpp・rclpy のノードや ros2 の道具とそのまま話せます。ROS 2 Jazzy で確かめています。最初の版 0.1.0 を出しました。kumu 追加 github.com/suru-lang/rclsuru@0.1.0 でプロジェクトに足します。

トピックと QoSサービスアクションパラメータ/rosout へのログuse_sim_timeros2 launch

std_msgs・geometry_msgs・sensor_msgs・nav_msgs などの型を約 200 個同梱しています。自分の .msg・.srv からも、する で書いた生成器で型を作れます。メッセージの CDR への直列化も する で書いています。作ったノードは普通の実行ファイルなので、ros2 run や ros2 launch から起動できます。

本体.suru — 1秒ごとに発行するノード
「rclsuru」 を 読み込んで 使う

始めする とは 以下の手順です
  n とは 「hello」 を ノード作成した 結果
  p とは 文字列型 を 「chatter」 へ n で 発行者作成した 結果
  （「こんにちは」 を p へ 発行する） を 1.0 で n に 周期登録する
  「始めました」 を n で 情報記録する
  n を スピンする
  以上です

始めする
$ kumu 追加 github.com/suru-lang/rclsuru@0.1.0
$ kumu 実行 &
$ ros2 topic echo chatter std_msgs/msg/String

アプリ手元の LLM と、ブラウザで話す

おはなし(ohanashi-ollama)は、手元の Ollama の LLM とブラウザでおしゃべりする Web アプリです。サーバーは する で約 4000 行で、1つの実行ファイルになります。会話は手元の SQLite にしまうので、外には出ません。

会話とスレッド決まり(OHANASHI.md)コーディングモード画像・PDFウェブ検索Docker の砂場Word・PDF を作るGitHub で PR通知

09 / 入れ方

導入はじめる

好きな方法で入れてください。pip で入れるインタプリタには Python 3.10 以降、速い道具には Go 1.23 以降、バイナリを作るには clang が要ります(macOS なら xcode-select --install)。標準ライブラリの API と組み込み関数は Read the Docs のドキュメント(英語)にあります。

pip

pip install suru-lang

Homebrew

brew install suru-lang/suru/suru
macOS と Linux。道具が全部入ります。

バイナリ
