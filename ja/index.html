01 / 文法

助詞括弧ではなく、助詞で

引数には格助詞を付けます。どの引数が何の役なのかは助詞で決まるので、並べる順番は自由です。関数の名前は文の終わりに来る「〜する」の動詞です。

リストは と で並べ、して で結果を次の関数に渡し、それぞれ でリストの要素ごとに関数を呼びます。

02 / 言語

機能おもちゃではない、本物の言語

日本語の見た目の下には、今どきの関数型言語の中身があります。型の推論、自分で定義する型、パターンマッチ、そして副作用を値として分けて扱う仕組みです。

型

型の推論と検査

Hindley–Milner の型推論で、実行する前にプログラム全体の型を調べます。型は書かなくてよく、書きたいところには宣言できます。

形

データとパターンマッチ

組(名前付きタプル)、選択肢のある型、型の引数、条件付きのパターンマッチ、場合ごとの関数定義、性質(型クラス)。

動

副作用は「動作」

表示や入力は「動作」という値です。「手順」で順に行います(Haskell の do 記法にあたります)。

速

ネイティブのバイナリ

LLVM IR を出し、clang で1つの実行ファイルにします。Go で書いたコンパイラ suruc は、IR を作るまでが元の版の 14〜35 倍速くなります。

並

本当に並列なスレッド

スレッドは CPU のコアの数まで同時に動きます。通路・ロック・枠・箱で値をやりとりし、GC もスレッドに対応しています。

繋

C・C++・Go を呼ぶ

型を宣言して名前を指すだけで、libc や libm、自分で作った共有ライブラリの関数を呼べます。

03 / 文体

文体2つの書き方

単語の間に空白を入れて書くことも、ふだんの日本語のように空白なしで「。」と「、」で書くこともできます。丁寧語の「します」も使えます。同じファイルで混ぜてもかまいません。

空白の書き方
a と b を 平均する とは 合計 / 2
ただし 合計 とは a + b

3 と 5 を 平均する
4
句読点の書き方
aとbを平均するとは、合計/2。ただし、合計とは、a+b。
3と5を平均します。
「できました」を表示します。
4

04 / ライブラリ

標準必要なものは、そろっています

標準ライブラリそのものが する で書かれています。「名前」 を 読み込む で、ファイル、時間と暦(和暦も)、JSON、TCP、スレッドと通路、プロセスとパイプ、共有メモリ、シグナルが使えます。インタプリタでも、コンパイルしたバイナリでも、同じコードが動きます。HTTP サーバー(静的ファイル配信とクライアントつき)・SQLite・正規表現は、kumu 追加 で足す標準の外のライブラリです。

05 / 道具

道具道具も日本語で

エラーの文も、コマンドも、道具も日本語です(必要なところには英語の別名もあります)。

書

VS Code

色分け、書きながらの型の検査、型のホバー、定義へ移動、補完、名前の変更。言語サーバー suru-ls が支えます。

検

点検

suru --点検 で、使っていない名前や書き方の混在などを知らせます。点検そのものも する で書いています。

対

対話モード

ファイルなしで suru を起動すると、答えを型と並べて返します: 9 は 数。

組

ビルドツール kumu

kumu 新規、kumu 実行 でプロジェクトを作って、組んで、動かします。設定ファイルも する の文です。

06 / 入れ方

導入はじめる

パッケージは準備中です。最初のリリースまでは、リポジトリから直接入れてください。インタプリタには Python 3.10 以降、速い道具には Go 1.23 以降、バイナリを作るには clang が要ります(macOS なら xcode-select --install)。

pip 準備中

pip install suru-lang

Homebrew 準備中

macOS と Linux。道具が全部入ります。

バイナリ 準備中

OS ごとに GitHub Releases から。

VS Code 準備中

Marketplace で「する」を検索。

今すぐソースから
$ pip install git+https://github.com/suru-lang/suru      # インタプリタ suru
$ go install github.com/suru-lang/suru/cmd/suruc@latest  # 速いコンパイラ
$ go install github.com/suru-lang/suru/cmd/kumu@latest   # ビルドツール
$ suru 挨拶.suru             # 実行する
$ suruc 挨拶.suru && ./挨拶   # ネイティブのバイナリにする
する
