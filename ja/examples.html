例

ローカル LLM とチャットする

自分のマシンで Ollama が動かしているモデルと、端末でチャットします。会話の履歴を覚えていて、モデルが書いたそばから答えを表示します。プログラムは する で約50行で、インタプリタでもネイティブのバイナリでも同じに動きます。

01準備

Ollama を入れてモデルを取ってきます。それから kumu のプロジェクトを作り、標準ライブラリの外にある HTTP のライブラリ suru-lang/http を足します。

端末
$ ollama pull llama3.2
$ go install github.com/suru-lang/suru/cmd/kumu@latest
$ kumu 新規 チャット
$ cd チャット
$ kumu 追加 github.com/suru-lang/http
「チャット」を作りました(cd チャット してから kumu 実行)
依存に「github.com/suru-lang/http@0.2.0」を足しました
「github.com/suru-lang/http@0.2.0」を取ってきました

02プログラム

本体.suru を次のように書きかえます。

本体.suru
# ローカル LLM(Ollama)とチャットする。答えは届いたところから表示する
「標準」 を 読み込んで 使う
「JSON」 を 読み込んで 使う
「HTTP/クライアント」 を 読み込む

発言 とは 役 と 内容 の 組

# Ollama に送る JSON: {"model":…, "messages":[{"role":…, "content":…}, …]}
発言 を 発言JSONにする は JSON
m を 発言JSONにする とは （（「role」 と （m の 役 の JSON文字列） の JSON項目） と （「content」 と （m の 内容 の JSON文字列） の JSON項目）） の JSON物

発言 の リスト を 要求本文にする は 文字列
履歴 を 要求本文にする とは
  （（「model」 と （「llama3.2」 の JSON文字列） の JSON項目） と （「messages」 と （（履歴 の それぞれ を 発言JSONにする） の JSON配列） の JSON項目）） の JSON物 を JSON文字列にする

# 届く1行は {"message":{"content":"…"}, …}。中の文字列が答えの断片
JSON を 文字値取得する は 文字列
（s の JSON文字列） を 文字値取得する とは s
v を 文字値取得する とは 「」

（JSON と 文字列） の 成否 を 断片にする は 文字列
（v の 成功） を 断片にする とは （（v から 「message」 を JSON取得する） から 「content」 を JSON取得する） を 文字値取得する
（e の 失敗） を 断片にする とは 「」

# 1行届くたびに、断片を改行なしで表示して、それまでの答えに足す
文字列 を 文字列 に 断片表示する は 文字列 の 動作
答え を 行 に 断片表示する とは 手順
  断片 とは 行 を JSON解析して 断片にする
  断片 を 続表示する
  答え + 断片 を 結果にする

文字列 の 有無 を 入力文にする は 文字列
（s の 有） を 入力文にする とは s
無 を 入力文にする とは 「」

発言 の リスト を 会話する は 数 の 動作
履歴 を 会話する とは 手順
  質問 とは 「あなた> 」 を 入力確認した 結果 を 入力文にする
  もし 質問 が 「」 ならば 改行 を 続表示する
  そうでなければ 履歴 + （（役 は 「user」 で 内容 は 質問 の 発言） を 空 に 挿入する） を 回答する

発言 の リスト を 回答する は 数 の 動作
履歴 を 回答する とは 手順
  「AI> 」 を 続表示する
  答え とは 「http://localhost:11434/api/chat」 に （履歴 を 要求本文にする） を 「」 から 断片表示すること で クライアント内の逐次投稿した 結果
  「」 を 表示する
  履歴 + （（役 は 「assistant」 で 内容 は 答え の 発言） を 空 に 挿入する） を 会話する

空 を 会話する

03動かす

kumu 実行 で、プロジェクトをネイティブのバイナリにして動かします。あなた> の後に質問を打ちます。何も打たずに Enter を押すか、Ctrl+D で終わります。

端末
$ kumu 実行
「チャット」0.1.0 を組みました(出力/チャット)
あなた> 3つの言葉で挨拶して
AI> Hello! Bonjour! こんにちは!
あなた> 日本語はどれ?
AI> 「こんにちは」が日本語です。
あなた>
メモ: 上のモデルの答えは見本で、実際の答えは変わります。続表示する と 入力確認する を使うので、する 0.2.0 以降が要ります。

04しくみ

発言を組にする

発言 とは 役 と 内容 の 組 で、役 と 内容 の2つを持つ型 発言 を作ります。役 は 「user」 で 内容 は 質問 の 発言 で1つ作れて、履歴はそのリストです。

JSON を組み立てる

標準の JSON ライブラリの JSON文字列・JSON項目・JSON物・JSON配列 で、値を JSON にします。それぞれ で、履歴の全部に 発言JSONにする をかけます。

場合ごとの定義

文字値取得する は、JSON の文字列のときと、それ以外のときの2つに分けて定義しています。読めない行も同じ書き方で扱います。JSON解析する は 成否 を返すので、断片にする を成功と失敗に分けて書きます。入力確認する は1行読んで 有無 を返すので、入力の終わりを例外なしで扱えます。

関数を渡して、流れてくる答えを受け取る

URL に 本文 を 初期 から 処理 で 逐次投稿する は、本文を POST して、返ってくる行が届くたびに 処理 を呼びます。断片表示すること と書くと、自分の関数そのものを値として渡せます。空の答え 「」 から始めて、断片を 続表示する(改行なしで表示)で出し、最後の答えが 答え の値になります。

手順の中の動作

表示・入力・要求の送信は 動作 です。手順 の中で順に動かし、…した 結果 で動作が作った値を受け取ります。会話する と 回答する が互いを呼ぶので、繰り返しの文がなくても会話が続きます。

05もっと先へ

HTTP ライブラリにある長い版は、モデルと URL を引数で受け取り、llama.cpp の llama-server や LM Studio などの OpenAI 互換のサーバーとも話せて、要求に失敗しても会話を続けます。
