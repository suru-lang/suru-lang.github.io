Tutorial

Learn する in one sitting

This tour takes you from “hello” to a compiled program. You don’t need to speak Japanese: each step explains the few words it uses. Every example on this page was run with する, and the output shown is what it printed.

01Setup

Install the interpreter from the repository (a package on PyPI is coming soon). It needs Python 3.10 or newer and nothing else.

terminal
$ pip install git+https://github.com/suru-lang/suru
$ suru --version
する 0.1.0

Save this line as hello.suru and run it with suru hello.suru.

hello.suru
「こんにちは、世界」 を 表示する
こんにちは、世界

Read it right to left like an English sentence: display (表示する) the string “Hello, world” (「こんにちは、世界」). Strings go in Japanese quotation marks 「」, and を marks the object of the verb. Lines that start with # are comments.

Tip: run suru with no file to open the interactive shell. Type an expression and it answers with the value and its type, such as 9 は 数 (“9 is a number”).

02Values and names

とは means “is defined as.” A name made of kanji, katakana or Latin letters can hold any value. A line that is just an expression prints its value.

values.suru
税率 とは 0.1           # tax rate
値段 とは 1200          # price
値段 * （1 + 税率）
「する」 + 「言語」
1320
する言語

Arithmetic uses the usual + - * / % ^ (full-width ＋ × ÷ work too), and + joins strings. Parentheses may be ASCII or full-width.

03Functions and particles

A function name is a verb that ends in する (“to do”). You define it by writing an example call with parameter names, then とは and the body.

square.suru
x を 二乗する とは x * x      # “to square x is x * x”
5 を 二乗する
25

Each parameter is tagged with a particle. When you call the function, the particles match the arguments to the parameters, so the order doesn’t matter:

divide.suru
a を b で 割った数にする とは a / b
10 を 2 で 割った数にする
2 で 10 を 割った数にする
5
5
ParticleRough meaningExample
をthe main objectx を 二乗する
にto, onto3 を 5 に 加算する
でby, with10 を 2 で 除算する

へtowards を 「a」 から 「b」 へ 置換する
よりthan(free for your own functions)

A function can use each particle only once. Calling it with a missing argument, or with a particle it doesn’t take, is an error that is reported before the program runs.

04Lists

と means “and,” and it builds a list. の (“of”) reads a property of a list: 先頭 (head), 残り (rest), 最後 (last) and 長さ (length).

lists.suru
数列 とは 1 と 2 と 3 と 4
数列 の 先頭
数列 の 長さ
数列 を 加算する
5 を 数列 に 追加する
1
4
10
（1 と 2 と 3 と 4 と 5）

The built-in 加算する (“add”) sums a whole list. 追加する (“append”) returns a new list, because every value in する is immutable. The empty list is 空.

05Pipelines

Change the ending する to して (“and then”) and the result flows into the を of the next verb. Long chains read like a sentence.

pipeline.suru
x を 二乗する とは x * x
3 を 二乗して 1 に 加算する      # square 3, then add 1
1 と 2 を 加算して 二乗する      # add 1 and 2, then square
10
9

06Functions as values

Ending a verb in すること (“the act of doing”) turns it into a value you can pass around. If you give it some arguments first, it is partially applied. An anonymous function is written x を 受け取って … を 返すこと (“take x and return …”).

higher.suru
x を 三倍する とは x * 3
数列 とは 1 と 2 と 3 と 4
数列 の それぞれ を 三倍する
数列 から （x を 受け取って x > 2 を 返すこと） で 選別する
数列 を 0 から 加算すること で 畳み込みする
数列 を （10 を 加算すること） で 写像する
（3 と 6 と 9 と 12）
（3 と 4）
10
（11 と 12 と 13 と 14）

それぞれ means “each”: 数列 の それぞれ を 三倍する triples each element (map). 選別する is filter, 畳み込みする is fold, and 写像する is map with a function value.

07Conditions

もし … ならば … そうでなければ … is “if … then … otherwise ….” It is an expression, so both branches are required. が compares for equality.

A name ending in である (“is …”) defines a predicate, a function that returns true (真) or false (偽). Its subject takes が, you negate it with でない (“is not”), and であること makes it a value.

even.suru
n が 偶数である とは n % 2 が 0
n を 判定する とは もし n が 偶数である ならば 「偶数」 そうでなければ 「奇数」
7 を 判定する
4 が 偶数である
3 が 偶数でない
（1 と 2 と 3 と 4） から 偶数であること で 選別する
奇数
真
真
（2 と 4）

Combine conditions with かつ (and) and または (or).

08Recursion and definitions by cases

Write a value or a pattern in place of a parameter name to define a function case by case. The first case that matches is used.

factorial.suru
0 を 階乗する とは 1
n を 階乗する とは n * （n - 1 を 階乗する）
10 を 階乗する
3628800

Wrap a call in parentheses when you use its result inside arithmetic, as in n * （n - 1 を 階乗する）. Lists split into head and rest with 先頭 は x で 残り は 他 (“the head is x and the rest is 他”), and 空 matches the empty list.

09Your own data types

か (“or”) lists the shapes a type can take. もし 値 が followed by indented cases is pattern matching. Indentation decides the structure, as in Python.

shapes.suru
図形 とは 半径 の 円 か 幅 と 高 の 長方形

形 を 面積にする とは
  もし 形 が
    半径 の 円 ならば 3 * 半径 ^ 2
    幅 と 高 の 長方形 ならば 幅 * 高

5 の 円 を 面積にする
幅 は 2 で 高 は 3 の 長方形 を 面積にする
75
6

Here a 図形 (shape) is either a 円 (circle) with a 半径 (radius) or a 長方形 (rectangle) with a 幅 (width) and 高 (height). Build values in order (5 の 円) or by field name (幅 は 2 で 高 は 3 の 長方形). If you leave a shape out of the match, the program is rejected before it runs. Records are written 点 とは 横 と 縦 の 組, and type classes are called 性質 (“traits”).

10Actions and procedures

Side effects such as 表示する (display) and 入力する (read a line) don’t happen when they are evaluated. They produce an action (動作), and actions at the top level are performed. To run several in order, put them in a 手順 (“procedure”) block. … した 結果 (“the result of having done …”) gives a name to an action’s result.

greet.suru
挨拶する とは 手順
  名前 とは 「お名前は? 」 を 入力した 結果
  「こんにちは、」 + 名前 + 「さん」 を 表示する

挨拶する
お名前は? 太郎
こんにちは、太郎さん

してから (“after doing”) passes an action’s result on to the next verb, as in 入力してから 表示する. This keeps pure code and effects apart, the same idea as monads in Haskell.

11Writing without spaces

Real Japanese has no spaces between words. Once a line contains 。 or 、, する splits words where the script changes (kanji, kana, numbers). 。 ends a sentence and 、 is just a pause for readability. You can also use the polite form: します means the same as する.

punct.suru
aとbを平均するとは、合計/2。ただし、合計とは、a+b。
3と5を平均します。
「できました」を表示します。
4
できました

ただし (“provided that”) adds a local definition to the definition just before it. Because hiragana is used for particles, a name that contains hiragana goes in 『』 brackets, for example 『おやつの数』.

12Types

Before running anything, する infers the type of every expression and stops if something doesn’t fit. Errors are in Japanese, with a line, a column and a marker.

oops.suru
x を 二乗する とは x * x
「三」 を 二乗する
エラー: 2行目 7文字目: 「二乗する」の「を」には数が必要ですが、文字列が渡されています
  「三」 を 二乗する
            ^

The message says: “line 2, column 7: the を of 二乗する needs a number, but a string was given.” Types are optional to write, but you can declare one with は:

declared.suru
数 を 二乗する は 数      # takes a number (数), returns a number
x を 二乗する とは x * x
4 を 二乗する
16

Type names include 数 (number), 文字列 (string), 真偽 (boolean), 数 の リスト (list of numbers) and 文字列 の 動作 (an action that yields a string). Run suru --検査 file.suru to check without running.

13Modules and the standard library

「数学」 を 読み込む (“load 数学”) loads 数学.suru from the same folder, and its names are used as 数学内の二乗する (“二乗する in 数学”). Write 「数学」 を 読み込んで 使う (“load and use”) instead to use the names without a prefix. The standard library loads the same way:

stdlib.suru
「標準」 を 読み込んで 使う
3 と 1 と 2 を 整列する
「a,b,c」 を 「,」 で 分割する
1 から 5 を 範囲にする
（1 と 2 と 3）
（「a」 と 「b」 と 「c」）
（1 と 2 と 3 と 4 と 5）

Other modules include ファイル (files), 時間 (time and calendar), JSON, スレッド (threads and channels) and プロセス (processes). A module can end with X と Y は 非公開とする。 to keep names private.

14Native binaries

The same programs compile to a single native executable through LLVM. You need clang on your machine. suru --翻訳 uses the reference compiler; suruc, written in Go, does the same job much faster.

terminal
$ go install github.com/suru-lang/suru/cmd/suruc@latest
$ suruc factorial.suru
$ ./factorial
3628800

For a whole project, use kumu (組む, “to assemble”). Its project file 組.suru is itself a する program.

terminal
$ go install github.com/suru-lang/suru/cmd/kumu@latest
$ kumu 新規 挨拶      # new project “挨拶” (kumu new also works)
$ cd 挨拶
$ kumu 実行           # build and run (kumu run)
「挨拶」0.1.0 を組みました(出力/挨拶)
こんにちは
