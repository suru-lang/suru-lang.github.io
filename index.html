する
A programming language in Japanese

Write code in Japanese.

する (suru, “to do”) is a statically typed functional language whose source code is Japanese. Particles mark the arguments, types are inferred for you, and your programs compile to fast native binaries.

01 / GRAMMAR

助詞Particles, not parentheses

In Japanese, little words called particles tell you what each noun does in a sentence. する uses them the same way: every argument is tagged with a particle, so arguments can come in any order and the function name always comes last, as a verb ending in する.

Lists are made with と (“and”), results flow forward with して (“and then”), and それぞれ (“each”) maps a function over a list.

02 / LANGUAGE

機能A real language, not a toy

Behind the Japanese surface is a modern functional core: inferred static types, algebraic data, pattern matching, and side effects kept apart as values.

型

Inferred static types

Hindley–Milner type inference checks the whole program before it runs. You never have to write a type, but you can declare one when you want to.

形

Data & pattern matching

Records, sum types, generic types, pattern matching with guards, definitions by cases, and type classes called 性質 (“traits”).

動

Effects as values

Printing and input are 入出力動作 (“input/output actions”) that you run in order between 以下の手順です and 以上です (“the procedure is as follows … that is all”), much like Haskell’s do notation.

速

Native binaries

The compiler emits LLVM IR and links it with clang into a single executable. A Go compiler, suruc, generates the IR 14–35× faster than the reference one.

並

Parallel threads

Threads run truly in parallel on every core. Share data through channels called 通路, locks, semaphores and atomic boxes, with a parallel garbage collector underneath.

繋

Call C, C++ and Go

Declare a type, point at a symbol, and call it. Use libc, libm, or any shared library you build yourself.

03 / STYLE

文体Two ways to write

Write with spaces between words, or write the way Japanese is really written: no spaces at all, sentences ending in “。” and pauses marked by “、”. You can even use the polite form します. Mix the styles freely in the same file.

04 / LIBRARY

標準Batteries included

The standard library is itself written in する. Load a module with 「名前」 を 読み込む and you have files, time and the Japanese calendar, JSON, TCP, threads and channels, processes and pipes, shared memory, and signals. The same code runs in the interpreter and as a compiled binary. An HTTP server (with static file serving and a client), SQLite and regular expressions are libraries outside the standard library that you add with kumu 追加.

05 / ROS 2

ロボットROS 2 nodes in する

rclsuru is a ROS 2 client library for する. Write nodes with topics, services, actions, parameters, logging and ROS time, and they talk to rclcpp and rclpy nodes and the ros2 tools as they are. Tested on ROS 2 Jazzy. Version 0.1.0 is out; add it to a project with kumu 追加 github.com/suru-lang/rclsuru@0.1.0.

topics + QoSservicesactionsparameters/rosout logginguse_sim_timeros2 launch

About 200 message types from std_msgs, geometry_msgs, sensor_msgs, nav_msgs and more come bundled, and a generator written in する makes types from your own .msg and .srv files. Messages are serialized to CDR in する itself, and a built node is a plain executable that ros2 run and ros2 launch can start.

hello.suru — a talker that publishes every second
「rclsuru」 を 読み込んで 使う

始めする とは 以下の手順です
  n とは 「hello」 を ノード作成した 結果
  p とは 文字列型 を 「chatter」 へ n で 発行者作成した 結果
  （「こんにちは」 を p へ 発行する） を 1.0 で n に 周期登録する
  「始めました」 を n で 情報記録する
  n を スピンする
  以上です

始めする
$ kumu 追加 github.com/suru-lang/rclsuru@0.1.0
$ kumu 実行 &
$ ros2 topic echo chatter std_msgs/msg/String

06 / OHANASHI

アプリChat with your local LLMs in the browser

Ohanashi (ohanashi-ollama) is a web app for chatting in the browser with the LLMs your local Ollama runs. Its server is about 4,000 lines of する and builds into a single executable. Conversations stay in a local SQLite file and never leave your machine.

conversations + threadsrules (OHANASHI.md)coding modeimages + PDFsweb searchDocker sandboxWord + PDF outputGitHub pull requestsnotifications

The model can run and check code in a Docker sandbox, read GitHub repositories, and open issues and pull requests. HTTP, WebSocket, SQLite, GitHub and Ollama each live in their own する library, so you can use them in your own apps too. How to use it →

terminal — run Ohanashi
$ ollama pull qwen3
$ git clone https://github.com/suru-lang/ohanashi-ollama
$ cd ohanashi-ollama
$ kumu 実行 &
$ open http://localhost:8080/   # open it in your browser
07 / TOOLS

道具Tooling that speaks Japanese too

Error messages, commands and tools all use Japanese, with English aliases where it helps.

書

VS Code

Highlighting, live type errors, hover types, go to definition, completion and rename, powered by the suru-ls language server.

検

点検 linter

suru --点検 finds unused names, mixed styles and more. The linter is written in する.

対

Interactive shell

Run suru with no file and every answer comes back with its type: 9 は 数.

組

kumu build tool

kumu 新規, kumu 実行: create, build and run projects. The project file is a する program.

08 / INSTALL

導入Get started

Pick whichever way you like. You need Python 3.10+ for the interpreter, Go 1.23+ for the fast tools, and clang to build binaries (on macOS, xcode-select --install).

pip

pip install suru-lang

Homebrew

brew install suru-lang/suru/suru
macOS and Linux, with every tool.

Binaries

GitHub Releases for each OS.

VS Code

Search “する” in the Marketplace.

latest, from source
$ pip install git+https://github.com/suru-lang/suru      # the suru interpreter
$ go install github.com/suru-lang/suru/cmd/suruc@latest  # fast compiler
$ go install github.com/suru-lang/suru/cmd/kumu@latest   # build tool
$ suru hello.suru            # run
$ suruc hello.suru && ./hello  # compile to a native binary
