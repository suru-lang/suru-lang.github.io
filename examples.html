Chat with a local LLM

A terminal chat with a model running on your own machine through Ollama. It keeps the conversation history and prints the answer word by word as the model writes it. The whole program is about 50 lines of する, and it runs the same in the interpreter and as a native binary.

01Setup

Install Ollama and download a model. Then make a kumu project and add the HTTP library, suru-lang/http, which is not part of the standard library.

terminal
$ ollama pull llama3.2
$ go install github.com/suru-lang/suru/cmd/kumu@latest
$ kumu 新規 チャット        # new project “チャット” (chat)
$ cd チャット
$ kumu 追加 github.com/suru-lang/http   # add the dependency (kumu add)
「チャット」を作りました(cd チャット してから kumu 実行)
依存に「github.com/suru-lang/http@0.1.0」を足しました
「github.com/suru-lang/http@0.1.0」を取ってきました

03Run it

kumu 実行 compiles the project to a native binary and starts it. Type a question after あなた> (“you”). An empty line or Ctrl+D ends the chat.

terminal
$ kumu 実行
「チャット」0.1.0 を組みました(出力/チャット)
あなた> Say hello in three languages.
AI> Hello! Bonjour! こんにちは!
あなた> Which one is Japanese?
AI> こんにちは is Japanese.
あなた>
Note: the model’s replies above are only an illustration; yours will differ. The program needs a する newer than 0.1.0 for 続表示する and 入力確認する.

04How it works

A record for each message

発言 とは 役 と 内容 の 組 defines a record type 発言 (“utterance”) with two fields, 役 (“role”) and 内容 (“content”). 役 は 「user」 で 内容 は 質問 の 発言 builds one, and the history is simply a list of them.

Building JSON

The standard JSON library turns values into JSON with words like JSON文字列 (string), JSON項目 (key–value pair), JSON物 (object) and JSON配列 (array). それぞれ (“each”) maps 発言JSONにする over the whole history.

Definitions by cases

文字値取得する (“get the string value”) is defined twice: once for a JSON string, and once for anything else. The same style handles a line that fails to parse: JSON解析する returns a 成否 (success or failure), and 断片にする has one case for each. 入力確認する reads a line and returns a 有無 (“there is / there isn’t”), so the end of input needs no exception.

Streaming with a function value

URL に 本文 を 初期 から 処理 で 逐次投稿する POSTs the body and calls 処理 once for every line of the reply, as it arrives. Writing 断片表示すること (“the act of showing a piece”) passes our function itself as a value. It starts from the empty answer 「」, prints each piece with 続表示する (“keep printing”, no newline), and the final answer becomes the value of 答え.

Actions in a procedure

Printing, reading input and sending requests are 動作 (actions). A 手順 (procedure) block runs them in order, and …した 結果 (“the result of having done …”) takes the value an action produced. 会話する and 回答する call each other, so the conversation is a loop without a loop statement.

05Going further

The longer version in the HTTP library takes the model and URL as arguments, also talks to OpenAI-compatible servers such as llama.cpp’s llama-server and LM Studio, and keeps going when a request fails.
